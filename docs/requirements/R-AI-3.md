# R-AI-3

プラグインが設計書から下書きしたモデルは、手で書いたモデルと、ノード、線、属性の大部分で一致する。

## 検証

X10 の例の依頼を3回行い、書かれたモデルを [benchmarks/process/model.yaml](../../benchmarks/process/model.yaml) と比べる。ノードはラベルが一致するものを同じとみなし、線は両端のノードと線の種類が一致するものを同じとみなし、属性は同じとみなしたノードの属性のキーと値の組で比べる。ノードと線の F1 値（適合率と再現率の調和平均）と、属性の一致率の、3回の平均が、ノード 0.8 以上、線 0.7 以上、属性 0.8 以上なら合格とする。
