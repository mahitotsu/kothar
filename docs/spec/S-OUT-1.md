# S-OUT-1：配置の結果の JSON

配置の結果を、次の形の JSON で出力する。

| キー | 中身 |
| --- | --- |
| `nodes` | ノードごとに、ID、領域、中心の座標、幅、高さ、ピン留めしたか |
| `edges` | 線ごとに、出る ID、入る ID、線の種類、経路の点列、ラベルの位置と大きさ |
| `groups` | グループごとに、ID、枠の左上の座標、幅、高さ |
| `pins` | ピン留めの数と、ピン留めしたノードの ID |

配列はモデルに書いた順、キーは上の順で出力する。
