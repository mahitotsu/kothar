# S-PLUGIN-2：モデルを下書きするスキル

`draft-model` のスキルは、AI に次の手順を指示する。

1. 設計書、語彙、文法と、文法の説明（ベンチマークの説明と同じ形の `.md`）を読む。属性と線の種類の意味は、語彙のファイルのコメントと文法の説明から読み取り、設計書の要素とつながりに当てはめる。
2. 語彙にある属性と線の種類だけを使って、モデルの YAML を書く。座標とピン留めは書かない。
3. エンジンで lint を実行する。入力の誤りか、割り当ての誤りによる違反があれば、モデルを直して繰り返す。設計書のとおりに書いたモデルで出る違反は、モデルの意味を変えて（要素を消す、付け替える、まとめる、分ける）消さず、残したまま報告する（[検証 0008](../spikes/0008-ai-eval.md)）。そのあと、エンジンで図を描く。
4. 最後に、ノードごとに、割り当てた属性と、設計書のどこ（節の名前か文）から読み取ったかを、表で示す。

エンジンの呼び方は S-PLUGIN-5 による。図はエンジンだけが描くので、同じモデルから CLI で描いた図と同じになる。
