# S-PLUGIN-2：モデルを下書きするスキル

`draft-model` のスキルは、AI に次の手順を指示する。

1. 設計書、語彙、文法を読む。
2. 語彙にある属性と線の種類だけを使って、モデルの YAML を書く。座標とピン留めは書かない。
3. エンジンで lint を実行する。入力の誤りか違反があれば、モデルを直して繰り返す。違反0件になったら、エンジンで図を描く。
4. 最後に、ノードごとに、割り当てた属性と、設計書のどこ（節の名前か文）から読み取ったかを、表で示す。

エンジンの呼び方は S-PLUGIN-5 による。図はエンジンだけが描くので、同じモデルから CLI で描いた図と同じになる。
