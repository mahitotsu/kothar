# S-PLUGIN-3：検査の誤りと違反を直すスキル

`fix-model` のスキルは、AI に次の手順を指示する。

1. エンジンで lint を実行し、入力の誤りと違反の一覧を得る。
2. 誤りと違反ごとに、原因と直し方を示し、モデルだけを直す。語彙と文法のファイルは変えない。ピン留めは足さない。違反の原因がピン留めなら、外すか座標を直す。
3. 直し方が1つに決まらないとき（存在しないノードへの線で、名前の近いノードが複数あるなど）は、描く人に確かめる。
4. lint が0件になるまで繰り返す。
