# S-GRAMMAR-1：文法の語彙と、文法から作るもの

文法には、次のものを書く。ノードの名前は参照せず、属性と線の種類だけを参照する。

| 語彙 | 書くこと |
| --- | --- |
| 軸 | 流れの向き（左から右など） |
| 領域 | 名前、位置（上段、本流、下段、端の列）、割り当てる属性の条件、優先順位 |
| 線の種類 | 条件（`kind` と相手の領域）、スタイル、出る辺、入る辺 |
| 規則 | 有効にする不変条件と、その引数 |

エンジンは、文法を1つの中間表現に変換し、そこから次の3つを作る。同じ中間表現から作るので、配置と検査の基準が食い違わない。

1. ELK に渡す入力（向き、ポートの辺、入れ子のグループ）
2. ELK の外で置く領域（上段、端の列）の置き方
3. リンターが検査する不変条件
