# ADR 0010: SVG へのフォントの埋め込み方

- 状態：承認
- 日付：2026-10-07

## 背景

ADR 0006 で、フォントファイルを同梱してそのメトリクスで文字幅を測り、SVG には同じフォントを指定すると決めた。その帰結として、SVG を表示する環境にそのフォントがなければ、表示される幅は測った幅とずれる。幅がずれると、測った幅では重ならないラベルが、表示では枠からはみ出したり、ほかの要素に重なったりする。同梱するフォントを選ぶ前に、SVG にフォントをどう持たせるかを決める。

SVG は図ごとにリポジトリにコミットされ、レビューで差分を読まれる。SVG が大きいほど、リポジトリが重くなり、差分も読みにくくなる。これは要件と約束からは直接導けないので、SVG の大きさを基準の1つにし、出どころを「この ADR」とする。

## 判断の基準

優先順に並べる。

1. 表示する環境にフォントがなくても、測ったフォントの字形で表示されること（必須）。判定：SVG の中の情報だけで、ブラウザが測ったフォントの字形を使えるか。出どころ：R-READ-1、R-LAYOUT-2
2. 同じ入力から、同じ SVG がバイト単位で出ること（必須）。判定：SVG に入れるフォントのデータが、同じ入力から同じバイト列になるか。出どころ：R-DET-1、R-CHECK-2
3. SVG が小さいこと。判定：フォントのために SVG に足される大きさを比べる。出どころ：この ADR
4. 図の差分が、意図の変更だけを表すこと。判定：ラベルを変えたときに、フォントのデータの部分にも差分が出るか。出どころ：P6

## 検討した選択肢

### 1. 埋め込まない

SVG にはフォントの名前（`font-family`）だけを書く。

- 長所：フォントのデータが入らないので、決定性は崩れない（基準2）。SVG に何も足されない（基準3）。フォントの差分も出ない（基準4）。
- 短所：表示する環境にフォントがなければ、別のフォントで表示され、幅がずれる（基準1。ADR 0006 の帰結）。

### 2. フォントのファイル全体を埋め込む

フォントのファイル全体を `data:` URL にして、SVG の `@font-face` に入れる。

- 長所：画像として表示される SVG でも、`data:` URL で入れたものは使える（基準1。[MDN：SVG as an image](https://developer.mozilla.org/en-US/docs/Web/SVG/Guides/SVG_as_an_image)）。同梱するファイルをそのまま入れるので、同じバイト列になる（基準2）。ラベルを変えても、フォントの部分は変わらない（基準4）。
- 短所：候補のフォントのファイルは 2.3〜9.4MB あり、図ごとにその大きさが足される（基準3。[検証 0004](../spikes/0004-font-metrics.md)）。

### 3. 図に使う字だけを抜き出して埋め込む

図に使う字だけを含むサブセットを作り、`data:` URL にして、SVG の `@font-face` に入れる。

- 長所：画像として表示される SVG でも、`data:` URL で入れたものは使える（基準1。MDN：SVG as an image）。例の図に使う97字のサブセットは、同じ入力から同じバイト列になった（基準2。検証 0004）。サブセットは 16〜26KB で、ファイル全体の1%未満だった（基準3。検証 0004）。
- 短所：ラベルに新しい字が加わると、サブセットが変わり、フォントの部分にも差分が出る（基準4）。

### 対照表

| 選択肢 | 基準1 | 基準2 | 基準3 | 基準4 |
| --- | --- | --- | --- | --- |
| 1. 埋め込まない | × | ○ | ○ | ○ |
| 2. ファイル全体を埋め込む | ○ | ○ | × | ○ |
| 3. 図に使う字だけを埋め込む | ○ | ○ | ○ | △ |

## 決定

選択肢3の「図に使う字だけを抜き出して埋め込む」を採る。必須の基準1と2を満たすのは選択肢2と3で、そのうち基準3で優れるのは選択肢3である。

## 帰結

- 表示する環境のフォントによらず、測った幅で表示される見込みである。実際にブラウザと GitHub で表示されるかは、R-READ-1 の確認で確かめる。
- ラベルに新しい字が加わると、SVG のフォントの部分にも差分が出る。差分のレビューでは、フォントの部分を読み飛ばす必要がある。
- 埋め込むサブセットは、フォントの改変に当たる。予約されたフォント名（Reserved Font Name）を持つフォントでは、その名前を使えない（[OFL FAQ](https://openfontlicense.org/ofl-faq/) の 2.6）。同梱するフォントを選ぶときの基準になる。
- R-READ-1 の確認で、埋め込んだフォントで表示されないブラウザが1つでもあれば、この決定を見直す。
