## PR/FAQ の見直し

このゲートで PR/FAQ を次のように変えた。

- 入口を Claude Code のプラグインにし、Claude Agent SDK からも使えるようにした。配置と検査は AI の外にあるエンジンに置き、CI では CLI だけで使えるようにした。
- 約束の一覧（P1〜P12）を加えた。企画書の利用場面のうち、コミットされた図が描き直した図と同じことを CI で確かめる、を P12 として加えた。

## 次のサイクルで扱う約束

フェーズ1では、MVP として次の約束を扱う。範囲は [計画](../plan.md#mvp) の MVP による。

| ID | 扱う理由 |
| --- | --- |
| P1 | 文法をモデルと分けて宣言することが、MVP の前提である |
| P2 | MVP の目標そのものである |
| P3 | MVP ではピン留めを使ってよく、その数を記録する |
| P4 | MVP の合格条件「元の図と同じ意図が読み取れる」に当たる |
| P5 | MVP の合格条件「文法違反がない」「重なりがない」を検査で確かめる |
| P6 | MVP の合格条件「決定性」に当たる |
| P10 | MVP の出力である |
| P12 | 決定性があれば、CLI だけで確かめられる |

扱わない約束と理由は次のとおり。

| ID | 扱わない理由 |
| --- | --- |
| P7 | モデルの形が固まるまで AI の機能は入れない（ADR 0003）。モデルの記述形式は、フェーズ1で決める |
| P8 | エンジンを呼ぶ方式の ADR がまだない。P7 と一緒に扱う |
| P9 | 2種類目の図は、MVP の次に扱う（計画） |
| P11 | MVP に含めない（計画） |
