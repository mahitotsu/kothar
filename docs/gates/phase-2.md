## このゲートで決めたこと

1. テストで検証する要件は、コミット 400a291 の CI（[実行の結果](https://github.com/mahitotsu/kothar/actions/runs/37794066782)）で、Linux と macOS の両方で `npm test` の28件がすべて合格し、両方の出力がバイト単位で一致したことをもって、合格とする。
2. 文法の設計は変えない。2種類の図（信頼境界の図、リクエストの流れの図）のために、文法に5つの語彙（列、出さないもの、グループの中という条件、枠をまたぐという条件、太い線）を足した。どれも特定の図の名前ではなく、配置と線の選び方の一般の語彙であり、モデルと語彙のファイルは変えずに済んだ。ADR 0002 と ADR 0009 の見直す条件（モデルを変えずに文法の差し替えだけで別の関心事の図を描けない、2つの文法が同じ語彙を参照できない）には当たらなかった。
