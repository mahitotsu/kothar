# X05 の例

## 入力

- 図：X01 の出力の SVG
- 読み手に渡す文法の説明：[benchmarks/sample-arch/grammar.md](../../../benchmarks/sample-arch/grammar.md) の軸、領域、線の種類、グループ

## 問いと正答

| 問い | 正答 |
| --- | --- |
| 外部のサービスはどれか | IdP、決済代行 |
| IdP を呼び出しているのはどれか | API Gateway |
| 決済代行を呼び出しているのはどれか | 注文サービス |
| 非同期の処理はどれか | イベントキュー、通知ワーカー |
| 横断的な関心事はどれか | ログ基盤、監視、鍵管理 |
| 横断的な関心事を使っている範囲はどこか | VPC 全体 |
| 利用者に向かって逆向きに届く通知はどれか | 通知ワーカーからユーザーへの線 |

## 期待する結果

- SVG が、Kothar なしにブラウザで表示される。
- 文法の説明と図だけを渡した読み手（人、または文法を知らない LLM）の正答率が、同じ問いを [handplaced.svg](../../../benchmarks/sample-arch/handplaced.svg) で答えたときと同程度以上である。
