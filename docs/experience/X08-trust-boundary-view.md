# X08：同じモデルを、信頼境界の図として描く

## 状況

X01 のモデル、文法、語彙がリポジトリにある。描く人は、セキュリティのレビューのために、どの呼び出しが信頼境界（VPC）をまたぐかを見せる図がほしい。構成図はそのまま残したいので、モデルは変えたくない。

## 操作

1. 信頼境界の図のための文法を、X01 と同じ語彙で書く。
2. X01 のモデルを、その文法で描く。

```
npx kothar render architecture.yaml --grammar trust.yaml --out trust.svg
```

`--grammar` の名前は仮である。

## 見えるもの

- モデルのファイルには差分がない。
- 図は、左から右へ3つの列に分かれている。
  - 左の列：信頼境界の外の利用者側のノード（ユーザー、CDN）
  - 中央：信頼境界（VPC）の中のノード。VPC の枠で囲まれている
  - 右の列：外部のサービス（IdP、決済代行）
- 信頼境界をまたぐ線（CDN から API Gateway、API Gateway から IdP、注文サービスから決済代行、通知ワーカーからユーザー）は、太い強調色の線で描かれ、境界の中だけの線は細い灰色の線で描かれる。
- 横断的な関心事（ログ基盤、監視、鍵管理）と、それへの線は、この図には出ない。
- X01 の構成図と同じく、lint で検査でき、違反は0件である。
