# X09：同じモデルを、リクエストの流れの図として描く

## 状況

X01 のモデル、文法、語彙がリポジトリにある。描く人は、新しく加わった開発者に、注文のリクエストがどのノードを順に通るかだけを説明したい。非同期の処理や横断的な関心事まで描くと、説明したいことが埋もれる。モデルは変えたくない。

## 操作

1. リクエストの流れの図のための文法を、X01 と同じ語彙で書く。
2. X01 のモデルを、その文法で描く。

```
npx kothar render architecture.yaml --grammar request-flow.yaml --out request-flow.svg
```

## 見えるもの

- モデルのファイルには差分がない。
- 図には、同期の呼び出し（`call`）でつながるノードと線だけが出る。ユーザーから CDN、API Gateway、注文サービスと在庫サービス、それぞれの DB へと、呼び出す順に左から右へ並ぶ。
- 外部のサービス（IdP、決済代行）は、X01 の構成図と同じく、呼び出す側の真上にある。
- 非同期の処理（イベントキュー、通知ワーカー）と横断的な関心事（ログ基盤、監視、鍵管理）、それらへの線は、この図には出ない。
- X01 の構成図と同じく、lint で検査でき、違反は0件である。
