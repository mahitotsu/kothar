# X02：同じ文法で別のシステムを描く

## 状況

X01 の文法がリポジトリにある。描く人は、別のシステム（経費精算システム）の構成図を描くことになった。このシステムにも、外部のサービス、非同期の処理、横断的な関心事がある。

## 操作

1. 経費精算システムのモデルを新しく書く。モデルからは X01 と同じ文法を参照し、文法は書かない。
2. 図を描く。

```
npx kothar render expense.kothar --out expense.svg
```

## 見えるもの

- 文法を1行も書かずに、経費精算システムの図ができる。
- X01 の図と同じ約束事で描かれている。外部の会計サービスは上段の呼び出す側の真上、承認のキューと通知ワーカーは下段、監査ログは右端の列にある。線の種類ごとのスタイルと出入りの辺も、X01 と同じである。
