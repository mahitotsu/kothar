# X04：意図の読み取りを妨げる配置が報告される

## 状況

描く人は X03 のピン留めの座標を書き間違え、イベントキューを本流の帯の中、在庫DB に重なる位置に固定してしまった。描く人はまだ気づいていない。

## 操作

```
npx kothar lint architecture.kothar
```

## 見えるもの

- 違反の一覧が出て、コマンドは失敗の終了コードで終わる。
- 違反ごとに、破った規則、対象のノードや線、何がどうなっているかが分かる。この例では、少なくとも次の2件が出る。
  - 規則1（重なり）：イベントキューと在庫DB が重なっている。
  - 規則3（領域）：イベントキューは下段に割り当てたのに、本流の帯の中にある。
- 違反の原因になったノードがピン留めされていることも分かる。
- ピン留めの座標を直して再び実行すると、違反は0件と表示され、コマンドは成功の終了コードで終わる。

読む人にとっては、検査を通った図だけがレビューに出てくるので、重なったラベルや、割り当てと違う位置のノードから意図を読み違えることがない。
