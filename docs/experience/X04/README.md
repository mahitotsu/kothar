# X04 の例

## 入力

X01 のモデル（[model.yaml](../../../benchmarks/sample-arch/model.yaml)）の queue に、次のピン留めを加えたもの。

| ノード | x | y |
| --- | --- | --- |
| queue | X01 の配置の結果での stockdb の中心の x 座標 | X01 の配置の結果での stockdb の中心の y 座標 |

ピン留めの座標は、X01 の配置の結果から決まるので、ファイルに書かない。受け入れテストは、X01 の配置の結果から座標を求め、モデルにピン留めを加えて検査する。

## 期待する出力

違反の一覧に、次の2件が含まれる。線の出入りの辺（規則2）などの違反もあわせて出うるが、その件数は期待値にしない。

| 規則 | 対象 | ピン留め |
| --- | --- | --- |
| 1（重なり） | queue、stockdb | queue |
| 3（領域） | queue | queue |

- コマンドは失敗の終了コードで終わる。
- ピン留めを X03 の位置に直すと、違反は0件で、コマンドは成功の終了コードで終わる。
