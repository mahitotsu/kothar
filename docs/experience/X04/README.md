# X04 の例

記述形式が未決なので、入力の中身を表で書く（[X01 の例](../X01/README.md) と同じ）。

## 入力

- 文法：X01 と同じ
- モデル：X01 のモデルに、次のピン留めを1件加えたもの

| ノード | 固定する位置 |
| --- | --- |
| queue | stockdb と同じ中心の座標 |

## 期待する出力

違反の一覧に、次の2件が含まれる。線の出入りの辺（規則2）などの違反もあわせて出うるが、その件数は期待値にしない。

| 規則 | 対象 | ピン留め |
| --- | --- | --- |
| 1（重なり） | queue、stockdb | queue |
| 3（領域） | queue | queue |

- コマンドは失敗の終了コードで終わる。
- ピン留めを X03 の位置に直すと、違反は0件で、コマンドは成功の終了コードで終わる。
