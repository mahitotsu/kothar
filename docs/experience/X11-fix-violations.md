# X11：検査の違反と書き間違いを、AI に直させる

## 状況

描く人は、サンプル構成図のモデルを手で直しているうちに、属性の名前を書き間違え、存在しないノードへの線を書き、ピン留めの座標を間違えた。lint を実行すると、入力の誤りと違反が報告される。

## 操作

Claude Code に、次のように頼む。

> architecture.yaml の lint の誤りと違反を直して。

## 見えるもの

- AI が、報告された誤りと違反ごとに、原因と直し方を示し、モデルだけを直す。文法と語彙のファイルは変えない。
- 属性の書き間違いは、語彙にある候補から正しいものに直る。存在しないノードへの線は、名前の近いノードへの線に直るか、直し方が決まらなければ描く人に確かめる。
- 違反の原因になったピン留めは、外すか、違反の出ない座標に直す。新しいピン留めは足さない。
- 直したあとの lint は、入力の誤りも違反も0件である。
- 描く人は、モデルの差分をレビューする。
