# X05：文法を知っている読み手が、初めて見る図を読む

## 状況

読む人は、注文システムの設計書のレビューを頼まれたエンジニアである。チームの文法は以前に一度読んだが、この構成図は初めて見る。Kothar は入れていない。

## 操作

1. 設計書のプルリクエストで、X01 で描いた `architecture.svg` を開く。GitHub の画面やブラウザで、ほかの画像と同じように開く。
2. 図を見て、次の問いに答える。
   - 外部のサービスはどれか。どのノードがそれを呼び出しているか。
   - 非同期の処理はどれか。
   - 横断的な関心事はどれか。どの範囲がそれを使っているか。
   - 利用者に向かって逆向きに届く通知はどれか。

## 見えるもの

- 図は、特別なツールなしにそのまま表示される。
- 問いの答えが、ノードの名前や説明の文を読まなくても、位置と線の形から決まる。外部のサービスは上段、非同期の処理は下段と破線、横断的な関心事は右端の列と細い点線、逆向きの通知は図の下を回る点線である。
