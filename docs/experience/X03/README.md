# X03 の例

## 入力

X01 のモデル（[model.yaml](../../../benchmarks/sample-arch/model.yaml)）の queue に、次のピン留めを加えたもの。

| ノード | x | y |
| --- | --- | --- |
| queue | X01 の配置の結果での stock の中心の x 座標 | X01 の配置の結果での queue の中心の y 座標 |

ピン留めの座標は、X01 の配置の結果から決まるので、ファイルに書かない。受け入れテストは、X01 の配置の結果から座標を求め、モデルにピン留めを加えて描く。

## 期待する出力

- queue の中心の x 座標が、ピン留めで書いた値になっている。
- ピン留めの数として1、ピン留めしたノードとして queue が、コマンドの出力と配置の結果の JSON の両方にある。
- grammar.md の規則1〜7の違反が0件である。
