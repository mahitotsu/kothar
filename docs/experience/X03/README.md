記述形式が未決なので、入力の中身を表で書く（[X01 の例](../X01/README.md) と同じ）。

## 入力

- 文法：X01 と同じ
- モデル：X01 のモデルに、次のピン留めを1件加えたもの

| ノード | 固定する位置 |
| --- | --- |
| queue | 中心の x 座標を、stock の中心の x 座標と同じにする |

ピン留めは座標で書く（[ADR 0002](../../adr/0002-diagram-input.md)）。上の「固定する位置」は、期待する見た目を言葉で書いたものである。座標の値は、X01 の配置の結果を見て描く人が決める。

## 期待する出力

- queue の中心の x 座標が、ピン留めで書いた値になっている。
- ピン留めの数として1、ピン留めしたノードとして queue が、コマンドの出力と配置の結果の JSON の両方にある。
- grammar.md の規則1〜7の違反が0件である。
