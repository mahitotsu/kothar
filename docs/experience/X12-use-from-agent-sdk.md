# X12：自分のツールから、Claude Agent SDK で使う

## 状況

描く人は、設計書を置くリポジトリに、設計書が更新されたらモデルの下書きを作り直す自分のツールを用意したい。ツールは Node.js のプログラムで、Claude Agent SDK を使う。

## 操作

1. ツールで、Claude Agent SDK に Kothar のプラグインを読み込ませる。
2. X10 と同じ依頼を、ツールから送る。

## 見えるもの

- Claude Code で使ったときと同じスキルとコマンドが、Agent SDK からも使える。
- X10 と同じく、語彙にある属性だけを使い、違反0件のモデルと図ができる。
- ツールのコードには、Kothar の配置や検査の処理を書かない。プラグインを読み込むだけで使える。
