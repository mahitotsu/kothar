# X03：文法で表せない位置にノードを固定する

## 状況

X01 の図ができた。元の図ではイベントキューが在庫サービスの真下にあり、在庫サービスから真下に降りる線で、在庫の変動がキューに流れることを見せていた。X01 の図では、イベントキューは下段にあるが、在庫サービスより右にずれている。文法には「下段のノードを、送る側の真下に置く」という規則がない。描く人は、文法を変えずに、この図だけイベントキューの位置を固定したい。

## 操作

1. モデルのイベントキューに、位置を固定する指定（ピン留め）を書く。
2. 図を描く。

```
npx kothar render architecture.kothar --out architecture.svg
```

## 見えるもの

- イベントキューが、指定した位置にある。ほかのノードは、X01 と同じく文法に従って置かれている。
- コマンドの出力に、ピン留めの数（1件）と、ピン留めしたノード（イベントキュー）が表示される。
- 配置の結果の JSON にも、ピン留めの数と、ピン留めしたノードが記録されている。
