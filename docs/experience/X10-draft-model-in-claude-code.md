# X10：Claude Code で、設計書からモデルを下書きさせる

## 状況

描く人のリポジトリに、作業プロセスの設計書（docs/process.md）と、作業プロセスの語彙と文法（benchmarks/process/ の vocabulary.yaml と grammar.yaml）がある。モデルはまだない。描く人は、Claude Code に Kothar のプラグインを入れてある。

## 操作

Claude Code に、次のように頼む。

> docs/process.md から、benchmarks/process/ の語彙と文法を使って、作業プロセスのモデルを下書きして。図も描いて。

## 見えるもの

- AI が、語彙にある属性と線の種類だけを使って、モデルのファイルを書く。モデルには座標もピン留めも書かない。
- AI が、Kothar で図を描いて検査し、違反や入力の誤りがあればモデルを直して、違反0件になるまで繰り返す。
- AI が最後に、どの要素にどの属性を割り当てたかを、設計書のどこから読み取ったかとあわせて一覧で示す。描く人は、この一覧とモデルの差分をレビューする。
- 描いた図は、同じモデルから CLI で描き直した図と同じである。AI がもう一度描いても、モデルが同じなら図は変わらない。
- 描く人が手で書いたモデル（benchmarks/process/model.yaml）と比べると、要素、線、属性の大部分が一致する。
