# X06：図の変更を、意図の変更としてレビューする

## 状況

X01 のモデル、SVG、配置の結果の JSON がリポジトリにコミットされている。注文サービスが注文の確定をイベントキューに送るようになったので、描く人はモデルに線を1本足す。

## 操作

1. モデルを変えずに、図を描き直す。
2. モデルに、注文サービスからイベントキューへの非同期の線を1本足して、図を描き直す。
3. 変更をプルリクエストにする。読む人が差分をレビューする。

```
npx kothar render architecture.kothar --out architecture.svg
git diff
```

## 見えるもの

- 1のあとは、SVG にも JSON にも差分がない。別の日、別のマシン（Linux と macOS）で描き直しても同じである。
- 3の差分は、モデルの1行の追加と、それに伴う SVG と JSON の変更だけである。
- 読む人は JSON の差分から、足した線の経路と、どのノードがどれだけ動いたかを読める。ノードの動きは、足した線に関わる範囲にとどまり、図全体が組み替わることはない。
