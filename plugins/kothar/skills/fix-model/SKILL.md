# Kothar のモデルの誤りと違反を直す

## 1. 検査する

Bash ツールで次を実行する。`kothar` はこのプラグインのコマンドである。

```
kothar lint <モデルのファイル>
```

## 2. 直す

誤りと違反ごとに、原因と直し方を短く示してから、直す。

- 直すのはモデルのファイルだけである。語彙と文法のファイルは変えない。
- 語彙にない属性や線の種類は、エラーの文に示された候補から、意味の合うものに直す。
- 存在しないノードへの線は、名前の近いノードへの線に直す。候補が1つに決まらないときは、直さずに描く人に確かめる。
- 違反の原因がピン留め（`pin`）なら、ピン留めを外すか、違反の出ない座標に直す。ピン留めを新しく足さない。
- モデルに書かれた要素やつながりを、誤りと違反を直すため以外に足したり消したりしない。
- 入力の誤り（書き間違い）は直す。違反のうち、要素やつながりの意味を変えないと消せないもの（要素を消す、線を別のノードに付け替える、まとめる、分ける）は直さずに残し、描く人に報告する。

## 3. 確かめる

もう一度 `kothar lint` を実行し、直せる誤りと違反がなくなるまで、1と2を繰り返す。

最後に、直したところの一覧（何を、なぜ、どう直したか）を示す。描く人は、モデルの差分をレビューする。
